# 背景音乐文件

当前发布版已包含 `background.mp3`：由用户提供的标准 MP3 转码为 64 kbps、44.1 kHz 双声道版本，时长约 112.9 秒，便于手机加载。

替换音乐时，请将获得授权、可由浏览器直接播放的音乐放在本目录，并使用以下任一文件名：

1. `background.mp3`
2. `background.m4a`
3. `background.ogg`

声音每次打开网页时默认开启。网页会在用户第一次普通触摸、点击或按键后尝试播放并自动循环；若第一次请求被手机浏览器拦截，后续普通操作会继续自动重试。浏览器不允许网页在没有用户手势时直接发声。

QQ 音乐的 `.mgg`、`.mgg2`、`.qmc` 或带 `STag` 的伪 `.flac` 文件不能直接使用，也不能仅靠修改扩展名转换。
